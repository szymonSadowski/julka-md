# Bun + Next.js Template

A minimal Next.js template powered by [Bun](https://bun.com).

## Quick Start

```bash
# Install dependencies
bun install

# Start development server
bun dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Prerequisites

- [Bun](https://bun.com/docs/installation) installed

## Tech Stack

- **Runtime**: [Bun](https://bun.com)
- **Framework**: [Next.js](https://nextjs.org)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## Scripts

- `bun dev` - Start development server
- `bun build` - Build for production
- `bun start` - Start production server

## Deployment

For deployment instructions and hosting options, see the Bun's [deployment guides](https://bun.com/docs/guides/deployment/vercel).
